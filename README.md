# 公的年金財政検証2024 — プログラム移植・可視化プロジェクト

厚生労働省が公開する「財政検証結果レポート2024」の推計プログラム(C/C++)を出発点に、
モダンな環境で再現・検証し、Webで動くインタラクティブBIとして可視化することを目指すプロジェクトです。

## 元データ

- プログラム: [財政検証（2024（令和6）年）関連資料](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/nenkin/nenkin/zaisei-kensyo/index.html) 内の公開zip
- 移植研究: 川出・佐藤・八塩・金田(2026)「公的年金財政検証プログラムのPythonへの移植」厚生労働行政推進調査事業 分担研究報告書

## 構成

```
source/    元プログラム(C/C++)。ASCII名にリネーム(元は日本語フォルダ名)
  wakuc/       外枠(人口・経済・労働の共通前提)
  emp_kyufu/   厚生年金・給付費推計(usys20)
  nat/         国民年金
  bas/         基礎年金
  emp_shushi/  厚生年金・収支計算(asys20)
  bunpu/       分布推計(ソースのみ、データは未収録・優先度低)
data/      各モジュールが参照する入力CSV(bunpu用データは容量が大きいため未収録)
.github/workflows/  GitHub Actions によるビルド・実行パイプライン
docs/      GitHub Pages で公開するBIダッシュボード
```

## ステータス

作業中。進捗は Issues / Actions を参照。

## ライセンス・利用について

元プログラムは厚生労働省が公開する政府標準利用規約に基づく想定です。本リポジトリは検証・研究目的の再現実装であり、
**公式の財政検証結果と完全に一致することを保証するものではありません**。政策判断には必ず厚生労働省の公式発表を参照してください。
