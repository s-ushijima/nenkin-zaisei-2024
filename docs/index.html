公的年金財政検証2024 再現ダッシュボード

厚生労働省が公開する財政検証プログラム（C/C++、5モジュール）をGitHub Actions上で再ビルド・実行し、長期の給付水準と財政見通しを算出したものです。算出値は「財政検証結果レポート2024」の公表値と突き合わせています。

検証・研究目的の再現実装です。公式の財政検証結果と完全に一致することを保証するものではありません。政策判断には必ず厚生労働省の公式発表を参照してください。

所得代替率の内訳

モデル年金（夫婦2人）の手取り賃金に対する比率。積み上げの高さが所得代替率で、上端の推移が給付水準そのものを表します。報酬比例部分は調整対象外のため横ばいで、低下分はすべて基礎年金部分から生じます。

年度末積立金（厚生年金・全制度合算）

各年度末の積立金残高。名目額のため、物価・賃金の上昇に伴って長期には金額そのものが増加します。

収入と支出（厚生年金・全制度合算）

保険料・国庫負担・運用収入を含む収入計と、給付・拠出金を含む支出計。いずれも名目額です。

公式レポートとの突合

厚生労働省「財政検証結果レポート2024」第3章の第3-7-6図・第3-7-10図に掲載された値との比較。公式値は小数第1位までの公表です。
